# Research artifacts

Raw material gathered from the eight repositories by the research pass, kept here so the case studies
can be written from real output rather than memory. Nothing in this folder is served as part of the site.

Per project:

- `visuals/*.txt` — verbatim terminal captures of the real tools, ANSI stripped, with the exact command
  and exit code in a header comment. Paths and addresses were redacted at capture time.
- `visuals/*.png` — screenshot masters (the web-ready versions live in `work/<slug>/media/`).
- `demo/` — material for interactive demos: AgentCrucible's full scenario × agent verdict matrix and
  engine bundle; Shipgate's core policy + scanner bundle and policy matrix; Recall's scheduler port with
  its parity cases; Spanforge's sample import; LocalPulse's harness; MoltDAO's assessment.

Before publishing anything from a private repository (ghost-notetaker, spanforge, localpulse, moltdao),
check it against the owner's approval: the GitHub one-liners and the captured visuals are approved;
deeper internals need a per-fact review.
